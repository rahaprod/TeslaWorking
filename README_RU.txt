TeslaWorking — Android-приложение для личной работы

Что уже реализовано в первой версии:
- Заказы: название/клиент, статус, цена, расходы, комментарий, дата и поиск.
- Задачи: срок, приоритет, отметка выполнения.
- Заметки: заголовок и текст.
- Калькулятор разницы между ценой и расходами.
- Статистика по заказам, задачам и суммарной прибыли.
- Тёмный интерфейс с фиолетовыми акцентами.
- Локальное хранение данных в WebView localStorage; аккаунт и интернет не нужны.

Сборка APK через GitHub Actions (не требует установки Android Studio на ПК):
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки TeslaWorking (включая скрытую папку .github).
3. Откройте вкладку Actions репозитория и разрешите запуск Actions, если GitHub попросит.
4. При загрузке в ветку main/master сборка запустится автоматически. Либо выберите workflow "Build TeslaWorking APK" и нажмите Run workflow.
5. Откройте завершённый запуск workflow, найдите раздел Artifacts и скачайте TeslaWorking-debug-apk.
6. Распакуйте скачанный архив и установите app-debug.apk на Android. При запросе разрешите установку из этого источника.

Локальная сборка через Android Studio:
- Откройте эту папку как проект.
- Используйте JDK 17, Android SDK Platform 35 и Gradle 8.11.1.
- Выполните Gradle task :app:assembleDebug.
- APK появится в app/build/outputs/apk/debug/app-debug.apk.

Важно:
- Это debug APK для личного использования, не подписанный release APK для публикации в Google Play.
- Исходный проект подготовлен, но APK ещё не собран и не протестирован на физическом телефоне.
- Данные приложения хранятся локально. При очистке данных приложения или его удалении они могут быть потеряны. Резервное копирование/восстановление пока не реализовано.
